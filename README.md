# android-test-campaigns
App Campaign Tester Enrollment

Pre-requisit:
- You need a Github account to contribute
- Your identifier is your Github account Name (in your Github account: go to Profile/Edit profile and copy your Name)

Instructions:

- Open an issue with title "request to collaborate"
- Once your user is added, clone this repository locally, or edit the file "campaigns.json" online
- Add your app to the JSON array declared in file: campaigns.json
- Add your name to at least 3 testing campaigns, and stay in for at least 14 days
- Once your campaign ends, delete the entry of your app in "campaigns.json"

Thanks.
